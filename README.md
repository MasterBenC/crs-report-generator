# 境外投资补税测算

本地 Agent skill。给有海外券商或银行账户、被税局要求补所得税、自己又算不清的人用。

客户不需要懂 CRS。CRS 只是税局怎么发现这些账户。这个 skill 做的是中介该做的那一段：把全年结单读清楚，算出大概要补多少税，并列出给税局准备什么。

适用于 WorkBuddy、豆包 Work、Claude、Codex 这类本地对话 Agent。不另做网站，结单默认留在本机。

这是测算底稿，不是税务意见，也不能代替正式申报。

## 它能帮客户回答的两件事

1. 今年大概要补多少税
2. 给税局准备哪些材料

默认结果只有四块，都用人话：

- 大概要补多少钱
- 这钱是怎么来的：分红多少、卖掉之后亏的减赚的还剩多少、外国已经扣过的税抵了多少
- 还缺哪些单子：缺了哪几笔会先不算
- 给税局准备什么：按年份归好的结单、测算表、缺材料说明

系统不收身份证。身份证由客户自己带去税局或交给中介。

## 对话怎么走

一次只问一句。客户可以说“我不知道”。

1. 您想算哪一年的税？
2. 这一年您主要住在哪儿？大部分时间在国内、两边跑、住在国外，或者说不清楚。不清楚时再问：在中国住满半年了吗？家里是不是还在国内？
3. 钱放在哪几家了？可以说“富途那个”“华泰那个”，也可以不说，直接传单子。
4. 把这一年能找到的月结单、年结单都传上来。
5. 这一年有没有分过红、收过利息，或者外国已经扣过税？

不会问：是不是税收居民、身份证号、TIN、买入价、金融机构编号。

## 税额怎么算

买入价只从结单、成交表、资金变动、持仓变动里读取。不让客户回忆，也不用现价或均价去估。

- 分红、利息单独算，不能用亏损冲掉
- 已经卖掉的股票、基金，先配上买入记录，再在同一年里盈亏互抵
- 没卖掉的浮盈浮亏不算
- 配不上买入记录的卖出，整笔先不算进确定税额，并写进缺材料清单
- 互抵后如果还是亏的，这一块按 0，不留到下一年，也不去冲分红

所以客户看到的“大概要补多少”，只包括已经对得上的部分。单子不全时，不会假装给一个精确总数。

## 券商支持

| 券商 | 状态 |
|------|------|
| 华泰 (HTSC) | 已有结单模板 |
| 富途 / 盈透 / 辉立 | 能识别名称，具体版式仍走通用提取和缺口清单 |
| 其他券商 | 能读到的字段就提取；不够就告诉客户还缺什么 |

第一版按全年、多文件归堆。不要指望单张日结单就能算出全年资本利得。

## 安装

把 `skills/crs-report-generator` 拷到当前 Agent 的 skills 目录：

```bash
bash install.sh ~/.claude/skills
bash install.sh ~/.codex/skills
```

依赖：

```bash
pip install pdfplumber openpyxl pytest
```

装好后，在对话里说：

> 帮我算一下海外账户今年大概要补多少税，我把结单发给你。

不要再说“生成 CRS 申报表”。

## 给顾问看的底稿

客户默认只看四块结果。顾问可以继续看：

- 账户盘点
- 成本匹配过程
- 年内盈亏互抵
- 原始提取结果

这些不作为给税局的材料。
